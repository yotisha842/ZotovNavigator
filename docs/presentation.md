## Слайд 5 — Решение

### Что на слайде
```
  Зотов.Навигатор — три формата, один продукт

  [Сайт Зотова]              [Телефон]               [Стойка при входе]
  Встраивается на        →   Мобильная версия     →   Интерактивный экран
  centrezotov.ru             без установки            + печатные буклеты
  через iframe               работает как PWA         прямо у входа

```

### Что говорим

> Мы сразу проектировали решение в трёх форматах — потому что у разных посетителей разные точки входа.
>
> Первый — встраивание на сайт Центра «Зотов».
>
> Второй — мобильная версия, просто открывается в браузере на телефоне. удобно при перемещении по центру.
>
>Но самое важное — третий формат. Именно при входе люди теряются больше всего. Поэтому мы разработали физический прототип навигационной стойки: интерактивный экран с нашей системой навигации и печатные буклеты рядом. Посетитель подходит, видит карту, строит маршрут — и идёт. Без ресепшн, без очереди, без вопросов.
>
>И во всех трёх форматах — один и тот же продукт, один код, одни данные.
