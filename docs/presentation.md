## Слайд 3 — Проблема

### Что на слайде
```
Мы пошли в центр сами и испытали трудности с навигацией.

● Здание круглое: нет привычных углов и ориентиров
● Непонятно, где находится определённая выставка и как пройти между этажами
● Сотрудники ресепшн отвечают на одни и те же вопросы весь день
● Навигация не интегрирована с актуальными событиями Центра
```

### Что говорим
> Перед тем как начать работу над проектом, мы всей командой посетили Центр «Зотов», потому что хотели понять проблему изнутри, а не только из брифа.
> И буквально сразу же столкнулись с тем, о чём написано в кейсе:
> Было сложно разобрать, где находится определенная выставка или мероприятие.
> Сотрудники ресепшн конечно помогли разобраться, но явно видно, что ни отвечают на одни и те же вопросы снова и снова.
> Это потеря времени и для посетителей, и для сотрудников.
> На фотографиях представлены навигационные ориентиры, которые уже есть: Присутствует инфографика, но первого взгляда она может быть непонятна, также есть подписи в лифте.
> Также на схеме не отмечены туалеты, и один из туалетов на первом этаже вообще никак не помечен и выглядит как техническое помещение.
> Мы решили исправить эту проблему

## Слайд 4 — Целевая аудитория

### Что на слайде
```
Кто теряется в Центре «Зотов»?

Новый посетитель
   → «Где гардероб? Где касса? Куда идти?»

Гость на конкретное мероприятие
   → «Лекция на 3-м этаже — как туда попасть?»

Семья с детьми
   → «Где мастер-класс? Где туалет? Где кафе?»

Планировщик дня
   → «Хочу успеть выставку, лекцию и кино — какой маршрут?»
```
### Что говорим
> Мы выделили четыре основных сценария использования — четыре типа посетителей,
> у каждого из которых своя «боль».
> Новичок не знает, с чего начать. Гость на событие теряет время в поисках зала.
> Семья с детьми хочет быстро найти всё нужное — и не стоять в очереди к ресепшн.
> А тот, кто хочет провести в центре целый день, испытывает трудности с тем, чтобы составить оптимальный маршрут.

## Слайд 5 — Решение

### Что на слайде
```
Зотов.Навигатор — интерактивная 3D-карта здания

● 3D-модель здания с отображением всех зон
● Клик на зону — описание и маршрут
● Построение маршрута до любого мероприятия
● Составной маршрут по нескольким точкам
● Поиск по названию зоны или события
● Афиша актуальных событий внутри карты
● Рекомендации из магазина по теме события
● ИИ-помощник для любых вопросов о Центре

```

### Что говорим

> Наше решение — веб-приложение с интерактивной
> 3D-картой здания, которое работает прямо в браузере без установки.
> Посетитель видит объёмную модель всех этажей, кликает на любое пространство и сразу видит — что там, когда следующее событие, как туда добраться.
> Можно выстроить маршрут до одного мероприятия или сразу по нескольким.
> Если интересно — система подберёт товары из магазина, которые перекликаются с темой выбранного события.
> Отдельная гордость — встроенный ИИ-помощник: он отвечает на вопросы не только о навигации, но и о самом Центре, его истории и программе — в любой формулировке.
> И всё это выдержано в эстетике конструктивизма, чтобы навигатор был органичной частью пространства, а не чужеродным интерфейсом.

## Слайд 6 — Техническая реализация

### Что на слайде
```
  Стек

  Backend      Java 17 + Spring Boot 3
  База данных  H2 in-memory
  Frontend     Vanilla JS + Three.js
  Маршруты     Алгоритм Дейкстры на графе зон
  AI-помощник  Gigachat API
  API-docs     Swagger UI / OpenAPI

```

### Что говорим
> По технической части кратко: бэкенд на Java Spring Boot, 
> фронтенд — чистый JS и Three.js 
> для 3D, маршрутизация через алгоритм Дейкстры, 
> ИИ-помощник подключён через Gigachat API. 
> Без фреймворков — намеренно: приложение должно встраиваться в WordPress одной строкой, и оно это уже умеет.

## Слайд 7 — MVP: что уже работает
### Что на слайде

```
3D-модель здания со всеми этажами и зонами
Клик на зону — описание, тип, текущие события
Переключение между этажами
Маршрут до любого мероприятия 
Составной маршрут по нескольким точкам
Обходной маршрут по всем текущим событиям
Поиск по названию зоны или мероприятия
Афиша событий внутри карты
Рекомендации товаров из магазина по теме события
ИИ-помощник — навигация, история, программа Центра
Физический прототип навигационной стойки с буклетами
```


Что говорим
> Всё это — не макет в Figma, а работающее приложение. Полный стек за время хакатона: от базы данных до 3D-анимации в браузере. Можно прямо сейчас открыть, выбрать несколько событий — система построит оптимальный маршрут по всем точкам и покажет его анимацией в 3D. Плюс мы сделали физический прототип: навигационная стойка с интерактивным экраном и печатными буклетами — так это могло бы выглядеть при входе в Центр.



## Слайд 8 — Перспективы развития

### Что на слайде
```
Дальнейшее развитие:

  1. Детализация 3D-модели
     Точная архитектура, навигационные точки, интерьеры

  2. Интеграция на сайт Центра «Зотов»
     Встраивание в centrezotov.ru через iframe

  3. Цифровые экраны внутри здания
     Интерактивные киоски на этажах и при входе

  4. Индор-навигация
     Позиционирование по Wi-Fi / BLE, маршрут «в
  реальном времени»

  5. Подключение живой базы данных
     ELMA365 API → события обновляются автоматически
```

### Что говорим
> Мы проектировали не демо для хакатона, а основу для реального продукта.
> Следующие шаги логичны и последовательны: сначала детализируем 3D-модель и интегрируемся на сайт Центра, затем расставляем интерактивные экраны внутри здания.
>Индор-навигация — позиционирование посетителя прямо на карте — реализуема через уже существующую Wi-Fi инфраструктуру здания.
> И как только Центр откроет доступ к ELMA365 — своей системе управления событиями — переключаем источник данных за полчаса. Архитектура уже готова.
